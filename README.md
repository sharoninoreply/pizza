# ניהול הפיצרייה

אפליקציית ניהול לפיצרייה: הזמנות, לקוחות, תפריט ודוחות.
העובדים נכנסים מכל דפדפן (מחשב, טאבלט או טלפון) עם סיסמת צוות אחת, ולא צריך חשבון Claude.

- **שרת:** Node.js + Express
- **בסיס נתונים:** SQLite, קובץ אחד בשם `data/pizzeria.db`
- **מסך:** `public/index.html`

## דרישות

Node.js בגרסה 18 ומעלה. מורידים מ־https://nodejs.org (גרסת LTS).

## אפשרות א׳: הפעלה על מחשב בחנות (רשת פנימית)

זו הדרך הפשוטה ביותר, והיא חינמית. המחשב בחנות משמש כשרת, וכל מכשיר שמחובר לאותו Wi‑Fi נכנס אליו.

```bash
cd pizzeria
npm install
```

**Windows (PowerShell):**
```powershell
$env:APP_PASSWORD="בחר-סיסמה-חזקה"; npm start
```

**Mac / Linux:**
```bash
APP_PASSWORD="בחר-סיסמה-חזקה" npm start
```

אחרי ההפעלה:
- **במחשב עצמו:** פותחים את http://localhost:3000
- **בטלפון או בטאבלט:** פותחים `http://<כתובת-ה-IP-של-המחשב>:3000`, למשל `http://192.168.1.20:3000`.
  - ב־Windows מוצאים את הכתובת עם `ipconfig`, בשורה IPv4.
  - ב־Mac: הגדרות ← רשת.
  - אם Windows שואל על חומת אש, מאשרים גישה ברשתות פרטיות.

המחשב צריך להישאר דלוק, והחלון של השרת פתוח, כל עוד עובדים.

## אפשרות ב׳: אירוח באינטרנט (גישה מכל מקום)

אפשר להעלות את הפרויקט לכל שירות אירוח שמריץ Node.js או Docker, למשל Railway, Render או Fly.io. בדרך כלל זה בתשלום חודשי נמוך.

שני דברים חובה:

1. **דיסק קבוע (Volume / Persistent Disk).** בלי דיסק קבוע, בסיס הנתונים יימחק בכל הפעלה מחדש של השרת.
   - מחברים את הדיסק לנתיב `/data`.
   - מגדירים משתנה סביבה `DB_PATH=/data/pizzeria.db`. ב־Dockerfile המצורף זה כבר מוגדר.
2. **משתני סביבה:**
   - `APP_PASSWORD`: סיסמת הצוות. חובה כשהאתר פתוח לאינטרנט.
   - `SESSION_SECRET`: מחרוזת אקראית ארוכה, משמשת לחתימת ההתחברות.

השירות מספק כתובת https, ואותה שולחים לעובדים.

ממשקי שירותי האירוח משתנים מדי פעם, לכן כדאי לעקוב אחרי המדריך העדכני של השירות שבחרת לפריסת אפליקציית Node.js או Docker עם Volume.

## משתני סביבה

| משתנה | ברירת מחדל | הסבר |
|---|---|---|
| `APP_PASSWORD` | ריק | סיסמת הצוות. אם היא ריקה, אין מסך כניסה, וזה מתאים רק לרשת פנימית. |
| `PORT` | `3000` | הפורט שהשרת מאזין לו |
| `DB_PATH` | `data/pizzeria.db` | המיקום של קובץ בסיס הנתונים |
| `SESSION_SECRET` | נגזר מהסיסמה | מפתח לחתימת ההתחברות |

## גיבוי

כל הנתונים נמצאים בקובץ אחד, `pizzeria.db`. כדי לגבות, מעתיקים אותו (ואת הקבצים `pizzeria.db-wal` ו־`pizzeria.db-shm` אם הם קיימים) למקום בטוח. הכי בטוח להעתיק כשהשרת כבוי.

## מבנה בסיס הנתונים

| טבלה | תוכן |
|---|---|
| `customers` | שם, טלפון (ייחודי), כתובת, הערות |
| `menu_items` | פיצות (מחיר לכל גודל: אישית, בינונית, משפחתית), תוספות, שתייה ומנות צד |
| `orders` | לקוח, משלוח או איסוף, כתובת, דמי משלוח, סכום, סטטוס, תאריך |
| `order_items` | שורות ההזמנה: פריט, גודל, כמות, מחיר יחידה, תוספות |

בהפעלה הראשונה נטען תפריט לדוגמה. עורכים אותו בלשונית "תפריט".

המחירים בהזמנה מחושבים תמיד בשרת לפי התפריט, ולא לפי מה שנשלח מהדפדפן.
